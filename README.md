## How this portfolio is organized

Each project folder follows the same structure, so a reviewer can navigate any of them the same way:

```
XX-project-name/
├── README.md          <- Problem statement, approach, findings, recommendation
├── data/
│   ├── raw/            <- Source data, left intentionally unclean (source of truth)
│   └── cleaned/        <- Cleaned/transformed data
├── spreadsheets/        <- Excel/Sheets workbooks
├── sql/                 <- Queries, schema, SQL-based analysis
├── powerbi/             <- .pbix files, dashboard screenshots
├── python/              <- Notebooks/scripts for deeper analysis
└── assets/              <- Charts, dashboard images used in the README
```
